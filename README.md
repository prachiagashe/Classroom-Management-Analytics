
# CRM-Based Classroom Management Analytics Dashboard

## Project Overview

This project is a Business Analyst portfolio project focused on analyzing student enquiries, admissions, follow-ups, and fee collection for a classroom management system.

The project uses Microsoft Power BI to transform sample data into interactive dashboards that help monitor key performance indicators (KPIs), identify trends, and support data-driven decision-making.

It also includes Business Requirements Document (BRD) and Functional Requirements Document (FRD) to demonstrate business analysis and requirements documentation skills.

**Note:** This is a demonstration project using synthetic sample data, not actual student records.

## Business Objectives

- Monitor total student enquiries and admissions.
- Analyze enquiries by course, class, source, and month.
- Track follow-up status and admission progress.
- Identify lost enquiries and reasons for lost opportunities.
- Analyze total fees and pending fees.
- Present business insights through interactive Power BI reports.
- Document business and functional requirements using BRD and FRD.

## Dashboard Pages

### 1. Enquiry Dashboard

Provides an overview of student enquiries and their outcomes.

**Key metrics and analysis:**
- Total Enquiries
- Total Fees
- Total Admissions
- Pending Fees
- Enquiries by Course/Subject
- Enquiries by Source
- Lost Enquiries by Reason
- Enquiries by Month
- Class slicer for filtering data

### 2. Admission Dashboard

Focuses on admission progress and fee-related analysis.

**Key metrics and analysis:**
- Follow-up Status
- Admission Status
- Students by Class
- Admissions by Month
- Admissions by Course/Subject
- Pending Fees by Course/Subject

### 3. Follow-up Dashboard

Focuses on follow-up monitoring and trends.

**Key metrics and analysis:**
- Follow-up Status
- Follow-up Date by Month
- Follow-up trend analysis using the available sample data

## Business Analysis Documentation

### Business Requirements Document (BRD)

The BRD describes the business problem, objectives, stakeholders, scope, business needs, and expected outcomes of the proposed CRM-based classroom management solution.

### Functional Requirements Document (FRD)

The FRD describes proposed system functionality, business rules, data requirements, functional requirements, acceptance criteria, and user acceptance testing considerations.

**Important:** Requirements documented for proposed features should not be interpreted as proof that those features are already implemented in the Power BI dashboard or a working CRM application.

## Dataset

The project uses an Excel sample dataset containing 200 synthetic records for demonstration and analysis.

The dataset supports analysis of enquiries, admission status, follow-up information, course or class categories, and fee-related metrics, depending on the available fields.

No real student data is intended to be included in this repository.

## How to View the Project

1. Open the dashboard PDF in the Reports folder to review the report pages.
2. Open the Power BI `.pbix` file using Microsoft Power BI Desktop to explore the report interactively.
3. Review the Excel dataset in the Dataset folder.
4. Read the BRD and FRD in the Documentation folder to understand the business requirements and proposed functionality.

## Expected Business Value

The dashboard demonstrates how classroom management data can be organized to improve visibility into enquiry trends, admission progress, follow-up activity, and outstanding fees.

It provides a foundation for identifying areas that may require attention and for supporting operational decisions.

## Project Limitations

- This is a portfolio and demonstration project.
- The dataset contains synthetic records.
- Dashboard results depend on the sample data and the measures implemented.
- Features described only in the BRD or FRD may remain proposed requirements.
